# Master Backtester

Fetches OHLCV candles, engineers ~100 technical indicators + price-action signals, then
exhaustively combo-backtests every indicator condition crossed with every signal to find
profitable strategies. Includes a Streamlit dashboard to explore results and backtest any
single found strategy on demand.

## Project layout

```
strategy_finder/   Data fetch + feature engineering + the combo search engine
backtesting/       Run ONE selected strategy standalone (used by the ui/ app)
ui/                Streamlit dashboard
data/              OHLCV cache + data/report.json (gitignored - regenerated by the search)
```

## Setup

Requires Python 3.13+ and [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

This creates `.venv/` and installs everything from `pyproject.toml`.

## 1. Run the strategy search

From the project root:

```bash
python3 -m strategy_finder.main
```

(Must be run as a module with `-m`, not `python3 strategy_finder/main.py` directly - the
package uses relative imports internally.)

This will:
1. Fetch OHLCV candles (or load them from the `data/` cache if already fetched).
2. Build ~100 indicator/price-action columns.
3. Exhaustively search combinations of conditions for profitable strategies.
4. Write everything - dataset stats, every profitable combo found, and the indicator
   diagnostics (contribution/redundancy/perfect-predictor/direction-vs-target-gap
   analysis) - to `data/report.json`.

Depending on `strategy_finder/main.py`'s settings (`COMBO_MAX_SIZE`, `COMBO_MAX_SEARCH_SECONDS`,
etc.), the search can take anywhere from minutes to much longer - it prints progress bars and a
short run summary (total time, rows/columns, where the output landed) when done.

## 2. Explore results / backtest a strategy

```bash
streamlit run ui/app.py
```

Then open the URL it prints (usually `http://localhost:8501`). Four tabs:

- **Overview** - dataset + backtest config + search funnel stats.
- **Combo Search Results** - filter (direction/size/trades/win-rate) and browse every
  profitable combo the search found, with charts.
- **Indicators** - per-indicator contribution/lift, redundant indicator pairs, the
  100%-win-rate scan, and the direction-right-but-target-missed diagnostic.
- **Backtest a Strategy** - pick any one strategy from the search results and run it
  standalone to see its full trade book, equity curve, and summary stats.

The dashboard reads `data/report.json`, so step 1 must have been run at least once first.

## Re-running after changing indicators/signals

If you add/remove columns in `strategy_finder/indicator_engine.py` or
`strategy_finder/price_action_engine.py`, re-run step 1 to regenerate `data/report.json` -
the dashboard and `backtesting/strategy_runner.py` both read the condition names straight out
of that file, so it needs to reflect whatever features currently exist.
